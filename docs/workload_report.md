# 투수 피로도·등판 가능 여부 모델

`python -m kbo_crawler.workload` 로 생성 (2026-10-31 05:13). 데이터: 2026 정규시즌·포스트시즌 160개 경기일, 마지막 2026-10-17. 검증은 2026-09-01 이전으로 학습하고 이후를 맞혀 본 결과입니다.

부상 기록은 공개 데이터에 없어서, 실제로 관찰되는 두 가지를 정답으로 씁니다: **엔트리에 있던 불펜 투수가 그날 나왔는가**(코칭스태프의 판단), **등판 뒤 3경기 안에 엔트리에서 빠졌는가**(부상·부진 말소).

## 1. 불펜 등판 가능성

- 학습 10,378건, 검증 3,065건 (엔트리에 있던 불펜 투수 x 경기일). 검증 구간 등판 비율 37.6%
- AUC **0.628** (투수별 평소 등판 비율만 쓴 기준 모델 0.611), 로그 손실 0.6420 (기준 0.6494)

가용도 = (지금 상태의 등판 확률) / (같은 투수가 연투·최근 부하 없이 쉬었을 때의 등판 확률). 피로도 = 100 x (1 - 가용도). 가용도 0.3 미만은 휴식 권장, 0.65 미만은 주의.

## 판정 규칙

- 불펜: 가용도 0.3 미만 휴식 권장 / 0.65 미만 주의 / 그 외 가능
- 선발: 마지막 선발 후 3일 이내 휴식 권장 / 4일 주의 / 5일 이상 가능
- 공통: 직전 등판 구속이 -1.5km/h 이상 떨어졌고 말소 위험이 평소의 2.0배 이상이면 최소 '주의'
- 경계값은 모델 숫자에 붙인 기준이며 의학적 판단이 아닙니다.
